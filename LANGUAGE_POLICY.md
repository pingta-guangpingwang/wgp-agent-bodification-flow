# Language policy / 双语政策

Chinese is the original drafting language. Chinese and English are both maintained release artifacts and should use the same section IDs, figure IDs, normative object names, and schema field names.

中文是原始创作语言。中英文均为正式维护的发布内容，并应保持章节号、图号、规范对象名和 Schema 字段一致。

Machine-readable semantics are defined by schemas and conformance tests. Before v1.0, if the natural-language editions contain an unresolved conflict, the Chinese edition is the temporary interpretive source and a public translation issue must be opened. This rule does not permit silent divergence.

机器语义由 Schema 和一致性测试确定。v1.0 前如自然语言版本存在尚未解决的冲突，以中文版作为临时解释来源，并必须创建公开翻译问题；不得以此为由默许两版漂移。

Translations must preserve `MUST / MUST NOT / SHOULD / MAY`, identifiers, event names, enum values, claim maturity, uncertainty, and limitations. Marketing intensifiers must not be added during translation.
