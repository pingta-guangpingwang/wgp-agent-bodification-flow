# Governance index / 治理文件索引

WGP-ABF keeps its governance documents at the repository root so GitHub can discover them without custom tooling.

WGP-ABF 将治理文件放在仓库根目录，便于 GitHub 和普通贡献者直接发现。

- [`GOVERNANCE.md`](../GOVERNANCE.md) — decision rights and project stewardship / 决策权与项目维护
- [`CONTRIBUTING.md`](../CONTRIBUTING.md) — contribution workflow / 贡献流程
- [`CODE_OF_CONDUCT.md`](../CODE_OF_CONDUCT.md) — community conduct / 社区行为准则
- [`LANGUAGE_POLICY.md`](../LANGUAGE_POLICY.md) — bilingual publication rules / 双语发布规则
- [`SECURITY.md`](../SECURITY.md) — vulnerability reporting / 漏洞报告
- [`TRADEMARKS.md`](../TRADEMARKS.md) — names, marks, and conformance claims / 名称、标识与合规声明
- [`AUTHORS.md`](../AUTHORS.md) and [`CITATION.cff`](../CITATION.cff) — authorship and citation / 作者权与引用
